🍽️ Zomato Data Analytics — Restaurant & Food Delivery Insights

An end-to-end Zomato Data Analytics project created to analyze restaurant data and generate meaningful business insights using Microsoft Excel, SQL, Statistics, and Power BI.

The project covers the complete analytics workflow — from raw data cleaning and exploration to SQL analysis and interactive dashboards.

---

📌 Project Overview

This project analyzes Zomato restaurant data to understand:

- Restaurant popularity
- Customer ratings and votes
- Restaurant types
- Popular locations
- Cuisine preferences
- Average cost for two people
- Online ordering trends
- Restaurant distribution
- Customer behavior and preferences

The final analysis is presented through Excel and Power BI dashboards supported by SQL-based analysis.

---

🎯 Project Objectives

- Clean and prepare the Zomato dataset
- Perform Exploratory Data Analysis (EDA)
- Analyze restaurant ratings and customer votes
- Understand restaurant and cuisine trends
- Analyze restaurant locations
- Study pricing patterns
- Analyze online ordering availability
- Perform business analysis using SQL
- Create an interactive Excel Dashboard
- Create an interactive Power BI Dashboard
- Generate actionable business insights

Major areas analyzed:

- Customer Votes

- Online Ordering
- Table Booking
- Restaurant Names

The analysis helped identify important patterns and trends within the restaurant industry.

---

🗃️ 3. SQL Analysis

SQL was used to answer business questions and extract useful information from the dataset.

Example:

SELECT Location,
       COUNT(*) AS Restaurant_Count
FROM zomato
GROUP BY Location
ORDER BY Restaurant_Count DESC;

Example analysis areas:

- Top restaurant locations
- Average restaurant ratings
- Most popular restaurant types
- Restaurants with highest votes
- Average cost by restaurant type
- Online ordering analysis
- Rating-based restaurant analysis
